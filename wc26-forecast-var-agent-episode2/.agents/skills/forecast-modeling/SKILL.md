# Skill: forecast-modeling

## Purpose
Use the forecasting tools instead of free-form guessing.

## Use when
- The user asks who is favourite, who will win, match probabilities, group probabilities, or tournament rankings.

## Procedure
1. Call the narrowest MCP forecast tool: match, group, or ranking.
2. Report probabilities, not deterministic winners.
3. Explain the biggest model inputs: strength rating, host advantage, travel/load proxy, and scenario adjustments.
4. Label bundled priors as demo inputs unless live sources were refreshed.
5. Avoid betting language and never recommend wagers.
