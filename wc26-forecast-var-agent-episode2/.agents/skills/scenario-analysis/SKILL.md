# Skill: scenario-analysis

## Purpose
Handle what-if inputs such as injuries, suspensions, squad changes, or rating shocks.

## Use when
- The user asks "what if", "without", "injury", "suspended", "rating points", or "scenario".

## Procedure
1. Treat the scenario as user-provided, not confirmed news.
2. Apply an explicit adjustment if supported by the tool.
3. Compare scenario output to the base model when possible.
4. Say that real injury news requires a live/paid/manual source refresh.
