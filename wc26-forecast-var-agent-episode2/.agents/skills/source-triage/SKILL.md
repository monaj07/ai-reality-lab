# Skill: source-triage

## Purpose
Select and disclose football data sources before making a forecast.

## Use when
- A question asks for a prediction, ranking, tournament field, team inputs, or source list.
- A fact may be current, licensed, stale, or missing.

## Procedure
1. Use the MCP source registry or tournament-field tools; do not rely on model memory.
2. Distinguish bundled demo data from live/paid/manual sources.
3. State source freshness and limitations.
4. Never claim to have used a disabled source such as betting markets unless it is explicitly enabled and provided.
5. Cite source ids for every factual or modelling input.
