# Skill: uncertainty-calibration

## Purpose
Prevent overconfident sports predictions.

## Use when
- A response includes probabilities, rankings, forecasts, or future claims.

## Procedure
1. Use calibrated language: favourite, underdog, range, scenario, uncertainty.
2. Include at least one uncertainty warning.
3. Refuse guarantees about future matches or tournament winners.
4. Keep probabilities to sensible precision; avoid fake exactness.
5. If asked for certainty, set abstained=true and explain why.
