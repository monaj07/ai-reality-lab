# football-research

Use this skill for football/soccer questions.

Guidelines:
- Distinguish national-team tournaments, club leagues, and player career history.
- For World Cup 2026 field/group questions, use `get_world_cup_group` before answering.
- Italy did not qualify for the bundled 2026 World Cup snapshot; do not place it in any group.
- For historical players from the 1970s/1980s, avoid modern advanced metrics unless the source explicitly contains them.
- Prefer caps/goals/source-card facts over vague legacy claims.
- For future results, abstain and explain that the event has not happened in the source snapshot.
