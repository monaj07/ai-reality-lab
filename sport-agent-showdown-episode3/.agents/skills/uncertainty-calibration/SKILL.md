# uncertainty-calibration

Use this skill for predictions, subjective comparisons and future results.

Guidelines:
- Say when the answer is unknowable from the source snapshot.
- Use `abstained=true` when asked for a guaranteed future result or an objective answer to a subjective question.
- You may still provide context, odds-style caveats or source-backed stats.
- Do not confuse model confidence with real-world certainty.
