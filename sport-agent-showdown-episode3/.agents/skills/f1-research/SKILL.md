# f1-research

Use this skill for Formula 1 questions.

Guidelines:
- Distinguish drivers, constructors/teams, calendar, venues, race winners and future predictions.
- Use `get_f1_driver_lineup` for line-up questions.
- Use `get_f1_calendar` for schedule and next-race questions.
- The bundled data intentionally contains a snapshot conflict: current Formula1.com schedule has 22 rounds, while the original FIA announcement says 24 races. Mention source/date differences when asked about total race count.
- Never guarantee a future race winner.
