# mixed-question-decomposition

Use this skill when a user question spans multiple sports or asks for a combined briefing.

Procedure:
1. Split the question into sport-specific subtasks.
2. Send each subtask to the relevant specialist/tool path.
3. Merge answers in a short structured format.
4. Keep citations attached to the facts they support.
5. If one subtask is uncertain, do not let it contaminate the rest of the answer.
